# Programming Model

- **2-1-A-Highly-Multithreaded-Coprocessor** — GPU as a coprocessor running many parallel kernel threads off-loaded from the host CPU.
- **2-2-Thread-Hierarchy** — Three-level hierarchy: threads in CTAs, CTAs in clusters, clusters in grids.
- **2-3-Memory-Hierarchy** — Multiple memory state spaces per thread, block, and grid with varying persistence and access costs.
