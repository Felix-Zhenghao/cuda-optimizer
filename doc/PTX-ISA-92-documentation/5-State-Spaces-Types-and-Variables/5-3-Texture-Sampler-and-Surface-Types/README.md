# Texture-Sampler-and-Surface-Types

- **5-3-1-Texture-and-Surface-Properties** — Dimension fields (width, height, depth) and channel_data_type/channel_order fields for `.texref` and `.surfref`.
- **5-3-2-Sampler-Properties** — Sampler and texture opaque type fields: normalized_coords, filter_mode, addr_mode, array_size, and force_unnormalized_coords.
- **5-3-3-Channel-Data-Type-and-Channel-Order-Fields** — OpenCL 1.0 enumeration values for channel data type (0x10D0–0x10DE) and channel order (0x10B0–0x10B9).
