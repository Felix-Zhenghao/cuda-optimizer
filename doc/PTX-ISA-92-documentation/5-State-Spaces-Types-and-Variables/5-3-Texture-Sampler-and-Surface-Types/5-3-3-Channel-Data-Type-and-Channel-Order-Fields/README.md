# 5.3.3. Channel Data Type and Channel Order Fields

Lists OpenCL 1.0 enumeration values for `channel_data_type` (15 values including CL_SNORM_INT8 through CL_FLOAT, hex range 0x10D0–0x10DE) and `channel_order` (10 values including CL_R through CL_LUMINANCE, hex range 0x10B0–0x10B9) used in PTX texture and surface descriptors.
