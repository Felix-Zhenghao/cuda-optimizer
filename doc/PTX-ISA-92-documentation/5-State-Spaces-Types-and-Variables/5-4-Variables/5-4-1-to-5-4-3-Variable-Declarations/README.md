# Variable-Declarations

Merged from: 5-4-1-Variable-Declarations to 5-4-3-Array-Declarations

Covers PTX variable declaration syntax specifying state space, type, name, optional array size, initializer, and fixed address. Predicate variables are register-only. Supports `.v2`/`.v4` vector prefixes for fundamental types up to 128 bits. Multi-dimensional arrays use C-style bracket syntax; first dimension may be omitted when an initializer is provided.
