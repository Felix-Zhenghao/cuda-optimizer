# Types

- **5-2-1-to-5-2-2-Fundamental-Types** — Core PTX type specifiers (signed/unsigned integer, floating-point, bit-size, predicate) and sub-word usage restrictions.
- **5-2-3-Alternate-Floating-Point-Data-Formats** — Non-fundamental FP formats (bf16, e4m3, e5m2, tf32, e2m1, e2m3, e3m2, ue8m0, ue4m3) stored in bit-size registers.
- **5-2-4-Fixed-point-Data-format** — The `s2f6` 8-bit signed fixed-point format (2 integer bits, 6 fractional bits, range −2.0 to +1.98).
- **5-2-5-Packed-Data-Types** — Packed floating-point, integer, and fixed-point types (2- and 4-element variants) used as instruction types with bit-size register operands.
