# Syntax

- **4-1-to-4-4-Source-Format** — ASCII source with C preprocessor support, C++-style comments, case-sensitive lowercase keywords, and extended identifier rules.
- **4-3-Statements** — Two statement types: dot-prefixed directives and opcode-based instruction statements with optional predicates.
- **4-5-Constants** — Literal constants and constant expressions with compile-time evaluation rules for integers and floating-point values.
