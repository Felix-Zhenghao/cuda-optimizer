# Specifying-Kernel-Entry-Points-and-Functions

- **11-2-1-Kernel-and-Function-Directivesentry** — `.entry` directive declaring kernel entry points with parameters passed via .param space.
- **11-2-2-Kernel-and-Function-Directivesfunc** — `.func` directive for device functions with input/return params, .noreturn, and .abi_preserve options.
- **11-2-3-Kernel-and-Function-Directivesalias** — `.alias` creates an alternate name for a non-entry function symbol within the same module.
