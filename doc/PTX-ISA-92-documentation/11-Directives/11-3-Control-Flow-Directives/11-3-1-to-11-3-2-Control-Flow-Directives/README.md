# Control-Flow-Directives

Merged from: 11-3-1-Control-Flow-Directivesbranchtargets to 11-3-2-Control-Flow-Directivescalltargets

Covers `.branchtargets` (declares list of potential branch targets for `brx.idx` indirect branch) and `.calltargets` (declares list of potential call targets for `call` indirect calls). Both associate label lists with a named label and require all targets to be within the same function.
