# Performance-Tuning-Directives

Documents performance-tuning directives including `.maxnreg` (max registers per thread), `.maxntid` (max CTA thread count), `.reqntid` (required CTA dimensions), `.minnctapersm`/`.maxctapersm` (CTA count per SM), `.noreturn`, `.pragma`, `.abi_preserve`/`.abi_preserve_control`, and `.attribute` for controlling register allocation, occupancy, and compiler optimization hints.
