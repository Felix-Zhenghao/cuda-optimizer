# Descriptions-ofpragmaStrings

Documents four .pragma string directives: `"nounroll"` (disable loop unrolling at module/function/loop scope), `"used_bytes_mask"` (bitmask indicating which bytes of a load are used, for optimization), `"enable_smem_spilling"` (spill registers to shared memory before local memory, sm_75+, PTX 9.0), and `"frequency"` (hint for basic block execution count, used by optimizer).
