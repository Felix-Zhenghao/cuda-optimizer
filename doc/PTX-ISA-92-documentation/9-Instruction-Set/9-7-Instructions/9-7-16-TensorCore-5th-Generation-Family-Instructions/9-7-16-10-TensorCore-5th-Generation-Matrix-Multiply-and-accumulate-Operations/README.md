Covers all aspects of 5th-generation TensorCore MMA operations: transpose/negate support per MMA kind; element packing formats for matrices A/B/D; data path layout organizations; shared memory layout and swizzling (K-major/MN-major, 32/64/128B swizzle modes); block scaling with scale factors A/B; sparse matrix variants (1:2 and 2:4); and the four MMA instruction variants (mma, mma.sp, mma.ws, mma.ws.sp).
