The `suld` instruction loads data from surface memory using surface coordinates. Supports 1D, 2D, 3D, and array geometries with unformatted binary access. Out-of-bounds behavior is controlled by `.clamp` field: `.trap` (fault), `.clamp` (nearest location), or `.zero` (return zeros). Supports cache operations and indirect access via `.u64` registers. Requires sm_20 for 3D and array variants.
