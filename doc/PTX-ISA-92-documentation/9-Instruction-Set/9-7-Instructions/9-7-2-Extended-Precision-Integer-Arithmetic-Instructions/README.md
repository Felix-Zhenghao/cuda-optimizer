Defines extended-precision integer arithmetic using a condition code register (CC.CF) for carry/borrow chaining. Instructions include `add.cc` (add with carry-out), `addc` (add with carry-in/out), `sub.cc` (subtract with borrow-out), `subc` (subtract with borrow-in/out), `mad.cc` (multiply-add with carry-out), and `madc` (multiply-add with carry-in/out). Used to implement multi-word arithmetic on 32- or 64-bit values.
