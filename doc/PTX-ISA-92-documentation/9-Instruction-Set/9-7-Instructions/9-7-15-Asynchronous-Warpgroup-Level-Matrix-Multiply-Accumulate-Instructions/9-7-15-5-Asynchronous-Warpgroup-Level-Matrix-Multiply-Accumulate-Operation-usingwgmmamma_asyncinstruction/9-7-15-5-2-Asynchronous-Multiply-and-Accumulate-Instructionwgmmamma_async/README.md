The `wgmma.mma_async` instruction performs asynchronous warpgroup-level matrix multiply-accumulate (`D = A*B + D`) supporting f16, bf16, tf32, FP8 (e4m3/e5m2), int8 (u8/s8), and binary (b1) data types. Matrix A can come from registers or shared memory (via descriptor); B always uses a shared memory descriptor. Requires `wgmma.fence`, `wgmma.commit_group`, and `wgmma.wait_group` for correct ordering. Requires `sm_90a`.
