Comprehensive reference for the `st` instruction, which stores a register value to an addressable state space. Covers cache operators, L1/L2 eviction priority hints, cache-hint policy, memory ordering qualifiers (`.weak`, `.volatile`, `.relaxed`, `.release`), MMIO stores, vector stores (`.v2`/`.v4`/`.v8`), and `.b128` type. Supports `.global`, `.local`, `.param`, and `.shared` state spaces.
