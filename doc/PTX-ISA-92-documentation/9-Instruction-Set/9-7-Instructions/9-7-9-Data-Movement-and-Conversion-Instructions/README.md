Covers all PTX data movement and conversion instructions. Includes cache operators and eviction hints; `mov` (scalar and vector pack/unpack); warp shuffle (`shfl.sync`); byte permutation (`prmt`); loads (`ld`, `ld.global.nc`, `ldu`); stores (`st`, `st.async`, `st.bulk`); multimem operations; prefetch and cache policy (`prefetch`, `applypriority`, `discard`, `createpolicy`); address conversion (`cvta`, `isspacep`, `mapa`, `getctarank`); type conversion (`cvt`, `cvt.pack`); asynchronous copies (non-bulk, bulk, tensor); and `tensormap.replace`.
