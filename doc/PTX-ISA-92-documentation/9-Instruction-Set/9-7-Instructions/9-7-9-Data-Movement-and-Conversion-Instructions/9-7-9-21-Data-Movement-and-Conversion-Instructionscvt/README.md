Comprehensive reference for the `cvt` instruction covering type conversion between integer and floating-point types, including half-precision (`.f16`, `.bf16`, `.tf32`), FP8 formats (`.e4m3x2`, `.e5m2x2`), FP6 formats (`.e2m3x2`, `.e3m2x2`), FP4 (`.e2m1x2`), and scaled exponent type `.ue8m0x2`. Covers rounding modes, saturation, ReLU activation, and block-scaling with `.scaled::n2::ue8m0`.
