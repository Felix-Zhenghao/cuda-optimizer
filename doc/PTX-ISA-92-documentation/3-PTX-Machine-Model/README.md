# PTX Machine Model

- **3-1-A-Set-of-SIMT-Multiprocessors** — Scalable array of SMs executing thread blocks as 32-thread SIMT warps with resource-limited concurrency.
- **3-2-to-3-3-Independent-Thread-Scheduling** — Volta+ per-thread scheduling and on-chip memory types: registers, shared, constant, and texture caches.
