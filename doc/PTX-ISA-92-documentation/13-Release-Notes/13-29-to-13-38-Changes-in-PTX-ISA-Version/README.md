# Changes-in-PTX-ISA-Version

Merged from: 13-29-Changes-in-PTX-ISA-Version-43 to 13-38-Changes-in-PTX-ISA-Version-21

Covers PTX ISA versions 2.1–4.3. Key additions: v4.3 adds lop3 instruction; v4.2 adds sm_53 and f16 types; v4.1 adds total_smem_size/dynamic_smem_size; v4.0 adds pm_64 counters; v3.x adds 64-bit gridid, globaltimer, sreg; v2.x adds sm_20/sm_21, separate compilation, independent texture mode, and function parameters.
