# Changes-in-PTX-ISA-Version

Merged from: 13-14-Changes-in-PTX-ISA-Version-77 to 13-28-Changes-in-PTX-ISA-Version-50

Covers PTX ISA versions 5.0–7.7. Key additions: v7.7 adds .param for isspacep/cvta; v7.6 adds szext/bmsk instructions and reserved smem registers; v7.5 adds wgmma/mbarrier; v7.4 adds .cluster features; v7.3 adds cp.async.bulk; v7.2 adds sm_87; v7.0 adds sm_80/async cp; versions 5.x–6.x add sm_5x/6x and various instructions.
