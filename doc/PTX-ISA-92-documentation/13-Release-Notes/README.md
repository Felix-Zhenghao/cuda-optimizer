# Release-Notes

- **13-1-to-13-3-Changes-in-PTX-ISA-Version-9** — PTX 9.0–9.2: sm_88/110 targets, enable_smem_spilling, .blocksareclusters, FP8/BF16 conversions, .ignore_oob.
- **13-4-Changes-in-PTX-ISA-Version-88** — PTX 8.8: sm_103/121 targets, family-specific "f" suffix targets, tcgen05.ld.red, 256b ld/st.
- **13-5-Changes-in-PTX-ISA-Version-87** — PTX 8.7: sm_120 target, tcgen05.mma extensions, FP16 accumulator for mma, new cvt types.
- **13-6-Changes-in-PTX-ISA-Version-86** — PTX 8.6: sm_100/101 targets, clusterlaunchcontrol, fence qualifiers, mixed-precision FP arithmetic.
- **13-7-to-13-12-Changes-in-PTX-ISA-Version-8** — PTX 8.0–8.5: mma.sp::ordered_metadata, FP8 types, tcgen05, wgmma, current_graph_exec register.
- **13-13-Changes-in-PTX-ISA-Version-78** — PTX 7.8: sm_89/90, .cluster scope, FP8 types (.e4m3/.e5m2), bf16, griddepcontrol, movmatrix/stmatrix.
- **13-14-to-13-28-Changes-in-PTX-ISA-Version** — PTX 5.0–7.7: wgmma, cp.async.bulk, sm_7x/8x targets, szext/bmsk, reserved smem registers.
- **13-29-to-13-38-Changes-in-PTX-ISA-Version** — PTX 2.1–4.3: lop3, sm_53, f16 types, smem size registers, pm_64 counters, separate compilation.
- **13-39-Changes-in-PTX-ISA-Version-20** — PTX 2.0: IEEE 754 compliance for sm_20, fma.f32, subnormal support, new div/rcp/sqrt.
