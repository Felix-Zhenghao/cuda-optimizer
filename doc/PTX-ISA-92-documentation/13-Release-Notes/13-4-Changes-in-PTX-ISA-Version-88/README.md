# 13.4. Changes in PTX ISA Version 8.8

PTX ISA 8.8 adds sm_103/sm_121 targets, introduces family-specific "f" suffix targets (sm_100f, sm_101f, sm_103f, sm_120f, sm_121f), extends min/max to three inputs, adds tcgen05.ld.red, supports 256b ld/st, and promotes numerous features to family-specific compatibility including ldmatrix/stmatrix shapes and tcgen05 variants.
