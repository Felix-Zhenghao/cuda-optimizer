# 13.6. Changes in PTX ISA Version 8.6

PTX ISA 8.6 adds sm_100/sm_100a/sm_101/sm_101a targets; extends cp.async.bulk with .shared::cta, fence with .acquire/.release/.sync_restrict, ldmatrix/stmatrix with new shapes and .b8 type; adds clusterlaunchcontrol; extends arithmetic to mixed-precision FP and .f32x2 types; and expands multimem and cvt with FP8/low-precision types.
