# Changes-in-PTX-ISA-Version-8

Merged from: 13-7-Changes-in-PTX-ISA-Version-85 to 13-12-Changes-in-PTX-ISA-Version-80

Covers PTX ISA versions 8.0–8.5. v8.5 adds mma.sp::ordered_metadata. v8.4 extends .b128 to sys scope and adds FP8 types for mma. v8.3 adds used_bytes_mask pragma. v8.2 adds tcgen05 instructions and wgmma extensions. v8.1 adds cluster-level shared memory and aggr_smem_size. v8.0 adds current_graph_exec register.
