# 13.5. Changes in PTX ISA Version 8.7

PTX ISA 8.7 adds sm_120/sm_120a targets, extends tcgen05.mma with mxf4nvf4 and scale_vec::4X, adds FP16 accumulator for mma, extends cvt with .rs rounding mode and new packed FP types, adds mmio/release/global qualifiers for st.async/red.async, and extends mma/.sp with e3m2/e2m3/e2m1 types.
