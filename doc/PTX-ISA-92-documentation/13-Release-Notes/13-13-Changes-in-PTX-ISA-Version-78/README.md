# 13.13. Changes in PTX ISA Version 7.8

PTX ISA 7.8 adds sm_89/sm_90 targets, .cluster scope for memory operations, shared::cluster sub-qualifier, cluster-level mbarrier operations, movmatrix/stmatrix instructions, FP8 types (.e4m3/.e5m2), bf16 for various instructions, griddepcontrol for dependent grid communication, and new mma shapes for f64.
