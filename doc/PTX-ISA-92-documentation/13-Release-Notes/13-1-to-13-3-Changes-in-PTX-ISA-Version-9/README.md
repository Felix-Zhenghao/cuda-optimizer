# Changes-in-PTX-ISA-Version-9

Merged from: 13-1-Changes-in-PTX-ISA-Version-92 to 13-3-Changes-in-PTX-ISA-Version-90

Covers PTX ISA versions 9.0–9.2. v9.0 adds sm_88/sm_110 targets, enable_smem_spilling/frequency pragmas, .blocksareclusters directive, and .abi_preserve directives. v9.1 adds .volatile for local memory, new FP8/BF16 cvt conversions, and multimem.cp.async.bulk. v9.2 adds u8x4/s8x4 types, .b128 for st.async, and .ignore_oob for cp.async.bulk.
