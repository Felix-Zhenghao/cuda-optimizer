# C

Merged from: 8-9-5-Causality-Order to 8-9-7-Communication-Order

Defines causality order (combining base causality order via program order and synchronization, with proxy-preserved variant for same-address cross-proxy), coherence order (partial transitive order over overlapping writes from morally strong or causality-related pairs), and communication order (non-transitive order relating writes to overlapping reads/writes capturing memory visibility).
