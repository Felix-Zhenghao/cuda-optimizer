# Scope

Merged from: 8-5-Scope to 8-7-Morally-strong-operations

Covers scopes (.cta, .cluster, .gpu, .sys) that define thread sets for strong operations; proxies (generic vs. texture/surface) requiring proxy fences for cross-proxy synchronization; and conflict/data-race definitions, including mixed-size data-race limitations and atomicity guarantees for overlapping atomic operations.
