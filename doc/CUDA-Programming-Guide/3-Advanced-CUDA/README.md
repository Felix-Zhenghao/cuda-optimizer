# 3. Advanced CUDA

- **3-1-Advanced-CUDA-APIs-and-Features** — Host-side advanced APIs: extended kernel launch, cluster launching, stream synchronization, PDL, batched memory transfers, and environment variables.
- **3-2-Advanced-Kernel-Programming** — GPU hardware model, SIMT, thread scopes, advanced synchronization primitives, async data copies, and L1/shared memory configuration.
- **3-3-The-CUDA-Driver-API** — Lower-level driver API: context management, module loading from PTX/cubin, kernel execution, and runtime/driver interoperability.
- **3-4-Programming-Systems-with-Multiple-GPUs** — Multi-GPU programming: device management, peer-to-peer transfers and direct memory access, managed memory, and IOMMU considerations.
- **3-5-A-Tour-of-CUDA-Features** — Survey of all advanced CUDA features categorized by purpose: performance, latency, functionality, interoperability, and fine-grained control.
