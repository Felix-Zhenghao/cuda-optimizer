# 5.3 Language Restrictions — Polymorphic Wrappers and Core C/C++ Restrictions

Covers `nvstd::function` polymorphic wrapper for device lambdas, and core C/C++ language restrictions in device code: no recursion for `__global__`, no function pointers to host functions, limited standard library support, and restrictions on exceptions, RTTI, and setjmp/longjmp.
