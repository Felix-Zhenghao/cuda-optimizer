# Technical-Appendices

- **5-1-Compute-Capabilities** — Feature support tables, SM specs, memory limits, and Tensor Core data types per compute capability (7.x–12.x).
- **5-2-CUDA-Environment-Variables** — Reference for all CUDA environment variables controlling devices, JIT compilation, execution, module loading, and error logging.
- **5-3-C-Language-Support** — nvcc support for C++11–C++20 features, standard library availability, lambda expression rules, and language restrictions in device code.
- **5-4-CC-Language-Extensions** — CUDA C/C++ extensions: execution specifiers, built-ins, atomic/warp functions, intrinsics, macros, optimization hints, and WMMA Tensor Core API.
- **5-5-Floating-Point-Computation** — IEEE-754 format details, CUDA compliance, rounding, FMA, and mathematical function error bounds for device code.
- **5-6-Device-Callable-APIs-and-Intrinsics** — Device-side barrier, pipeline primitives, Cooperative Groups API, and dynamic-parallelism Device Runtime API reference.
- **5-7-CUDA-C-Memory-Model** — Thread scope extensions to C++ memory model with atomicity rules and data race definitions for multi-GPU systems.
- **5-8-CUDA-C-Execution-model** — Forward progress guarantees for CUDA device threads, CUDA API progress semantics, and stream dependency examples.
