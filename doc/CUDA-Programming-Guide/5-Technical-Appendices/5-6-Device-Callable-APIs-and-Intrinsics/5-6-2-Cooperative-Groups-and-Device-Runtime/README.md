# 5.6 Device-Callable APIs and Intrinsics — Cooperative Groups and Device Runtime

- **cooperative-groups-core-classes** — Core Cooperative Groups API: `thread_block`, `thread_block_cluster`, `grid_group`, and partition/coalesced group types.
- **cooperative-groups-reduce-scan-sync** — Cooperative Groups headers for parallel reduce, inclusive/exclusive scan, and group synchronization operations.
- **cuda-device-runtime** — Device Runtime API for dynamic parallelism: device-side launch, memory, streams, error handling, and device management.
