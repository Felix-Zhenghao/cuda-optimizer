# 5.6 Cooperative Groups — Core Classes (cooperative_groups.h)

API reference for `thread_block`, `thread_block_cluster`, `grid_group`, `coalesced_group`, and `thread_group` types. Documents member functions: `sync()`, `size()`, `thread_rank()`, `group_index()`, and partition/coalescing operations for forming subgroups within a warp or block.
