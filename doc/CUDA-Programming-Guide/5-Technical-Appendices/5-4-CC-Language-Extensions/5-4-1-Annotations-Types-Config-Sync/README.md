# 5.4 C/C++ Language Extensions — Annotations, Types, Configuration, and Synchronization

- **function-variable-annotations-and-types** — Execution/memory space specifiers (`__host__`, `__device__`, `__global__`) and built-in types and variables (threadIdx, blockIdx, etc.).
- **kernel-configuration-and-synchronization** — Kernel launch configuration syntax (`<<<...>>>`) and thread synchronization primitives including `__syncthreads` and cooperative barriers.
