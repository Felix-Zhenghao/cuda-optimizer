# 5.4 Language Extensions — Function/Variable Annotations and Built-in Types

Reference for `__host__`, `__device__`, `__global__`, `__managed__`, `__constant__`, `__shared__` specifiers. Covers built-in vector types (int2, float4, etc.), built-in variables (threadIdx, blockIdx, gridDim, blockDim, warpSize), and texture/surface reference types.
