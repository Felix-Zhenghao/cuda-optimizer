# 5.4 Language Extensions — Debugging Utilities and Warp Matrix Functions

Covers device-side debugging: `__trap()`, `assert()`, `__assertfail()`, and `printf` in kernels. Also documents the WMMA API (`nvcuda::wmma`) for Tensor Core warp matrix operations including `load_matrix_sync`, `mma_sync`, and `store_matrix_sync` for compute capability 7.0+.
