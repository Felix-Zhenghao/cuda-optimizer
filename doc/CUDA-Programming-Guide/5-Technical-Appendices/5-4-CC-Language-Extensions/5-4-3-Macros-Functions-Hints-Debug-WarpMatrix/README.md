# 5.4 C/C++ Language Extensions — Macros, Functions, Hints, Debugging, and Warp Matrix

- **macros-functions-and-hints** — CUDA-specific macros (`__CUDA_ARCH__`), device-callable functions (intrinsics, DPX, memory hints), and compiler optimization hints.
- **debugging-and-warp-matrix** — Debugging utilities (`__trap`, `assert`) and WMMA Tensor Core warp matrix operations for compute capability 7.0+.
