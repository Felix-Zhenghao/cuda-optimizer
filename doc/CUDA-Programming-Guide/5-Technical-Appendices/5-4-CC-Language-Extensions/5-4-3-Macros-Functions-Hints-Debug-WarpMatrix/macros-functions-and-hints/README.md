# 5.4 Language Extensions — Macros, Device Functions, and Optimization Hints

Documents `__CUDA_ARCH__` and architecture feature macros, device-callable math intrinsics (`__sinf`, `__expf`, etc.), memory access hints (`__ldg`, `__stwt`), DPX dynamic programming instructions, and compiler hints (`#pragma unroll`, `__builtin_assume`, `__restrict__`).
