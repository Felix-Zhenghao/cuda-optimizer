# CUDA Programming Guide

Official NVIDIA CUDA Programming Guide documentation, covering the full CUDA platform from introductory concepts through advanced features and technical reference appendices.

## Contents

- **1-Introduction-to-CUDA** — GPU architecture motivation, CUDA programming model (threads/blocks/grids/memory), and platform software stack.
- **2-Programming-GPUs-in-CUDA** — Hands-on CUDA C++: kernel writing, SIMT execution, memory spaces, streams, async execution, unified memory, and nvcc.
- **3-Advanced-CUDA** — Advanced APIs, kernel programming (synchronization, async copies), driver API, multi-GPU systems, and feature survey.
- **4-CUDA-Features** — Deep-dive into 20 CUDA features: unified memory, graphs, cooperative groups, green contexts, async barriers, pipelines, TMA, IPC, and more.
- **5-Technical-Appendices** — Compute capability tables, environment variables, C++ language support, CUDA extensions, floating-point details, device APIs, and memory/execution models.
- **6-Notices** — Legal disclaimers and trademark notices. No technical content.
