# 2. Programming GPUs in CUDA

- **2-1-Intro-to-CUDA-C** — Kernels, triple-chevron launch, thread indexing, and unified vs. explicit GPU memory management with complete examples.
- **2-2-Writing-CUDA-SIMT-Kernels** — SIMT model, thread hierarchy, all GPU memory spaces, coalesced access, shared memory bank conflicts, atomics, and SM occupancy.
- **2-3-Asynchronous-Execution** — CUDA Streams, Events, callback functions, stream ordering, blocking/non-blocking semantics, and intro to CUDA Graphs.
- **2-4-Unified-and-System-Memory** — Unified virtual address space, unified memory paradigms (ATS/HMM/limited), prefetch hints, and page-locked mapped memory.
- **2-5-NVCC-The-NVIDIA-CUDA-Compiler** — nvcc compilation workflow, GPU architecture targeting, separate compilation with LTO, and key compiler flags.
