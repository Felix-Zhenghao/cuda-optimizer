# 2.2 Writing CUDA SIMT Kernels — SIMT, Thread Hierarchy, and Memory Spaces

Explains the SIMT execution model and warp divergence, the 1D/2D/3D thread-block-grid hierarchy with built-in variables, and all GPU memory types: global (persistent, device-wide), shared (on-SM scratchpad, static and dynamic allocation), registers, local memory (thread-private but device-resident), constant memory, L1/L2 caches, and distributed shared memory for thread block clusters.
