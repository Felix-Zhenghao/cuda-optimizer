# 4.16.1-3. Virtual Memory Management: Basics and Unicast Sharing

Introduces the CUDA Virtual Memory Management API for fine-grained control over physical memory and virtual address spaces. Covers key definitions (physical memory handles, virtual address ranges, mappings), support query APIs, API overview, and unicast memory sharing: allocating and exporting handles, importing on other processes, reserving virtual address space, mapping memory, setting access rights, and releasing resources.
