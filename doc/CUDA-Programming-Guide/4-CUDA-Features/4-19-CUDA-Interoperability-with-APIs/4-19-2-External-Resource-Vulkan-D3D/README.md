# 4.19.2.1-2. External Resource Interoperability: Vulkan and Direct3D

Details the external resource interoperability API for importing memory and synchronization objects across CUDA and other APIs. Covers Vulkan interop: importing Vulkan memory allocations, mipmapped arrays, and semaphores into CUDA. Also covers Direct3D 12 and 11 interop: importing D3D heap allocations and fences as external CUDA semaphores.
