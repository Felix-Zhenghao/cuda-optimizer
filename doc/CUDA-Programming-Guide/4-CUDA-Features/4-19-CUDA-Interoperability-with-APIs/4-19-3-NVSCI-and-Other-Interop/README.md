# 4.19.2.3. NVSCI Interoperability

Covers NVIDIA Software Communication Interface (NvSci) interoperability with CUDA, enabling memory and synchronization object sharing across processes and heterogeneous components. Explains NvSciSync and NvSciBuf integration, importing NvSci memory as CUDA external memory, using NvSciSync objects as CUDA external semaphores, and signaling/waiting patterns.
