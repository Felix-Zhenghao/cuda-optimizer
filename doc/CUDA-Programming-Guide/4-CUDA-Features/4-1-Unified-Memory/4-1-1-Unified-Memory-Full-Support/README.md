# 4.1.1. Unified Memory on Devices with Full CUDA Unified Memory Support

Covers unified memory behavior on systems with full CUDA support (hardware-coherent systems like NVIDIA Grace Hopper, and software-coherent Linux HMM systems). Includes in-depth examples using system-allocated memory (malloc, stack, global variables), page table coherency concepts, access counter migration, atomic accesses, performance guidance on avoiding GPU-resident memory writes from CPU, and memory prefetching techniques.
