# 4.1.2-4. Unified Memory: Managed Memory, Windows/WSL/Tegra, and Performance Hints

Covers unified memory on devices with only CUDA managed memory support (compute capability 6.x without pageable access), unified memory on Windows, WSL, and Tegra (limited support with restricted features), and performance hints including prefetch APIs, usage hints (read-mostly, preferred location), and guidance for optimizing memory access patterns.
