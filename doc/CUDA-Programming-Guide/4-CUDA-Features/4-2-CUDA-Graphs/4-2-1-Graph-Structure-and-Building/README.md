# 4.2.1-2. CUDA Graphs: Structure and Building

Introduces CUDA Graphs as a work-submission model with reduced CPU launch overhead. Covers graph node types (kernel, memcpy, memset, CPU function, conditional, memory nodes, child graphs), edge data for dependency control, and graph creation via the explicit Graph API and stream capture. Explains the three stages: definition, instantiation, and execution, with code examples.
