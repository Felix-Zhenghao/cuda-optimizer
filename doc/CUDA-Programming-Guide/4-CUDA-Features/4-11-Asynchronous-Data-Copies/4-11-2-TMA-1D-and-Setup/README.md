# 4.11.2.1. TMA for 1D Array Transfers

Introduces the Tensor Memory Accelerator (TMA) for high-throughput asynchronous data movement between global and shared memory. Covers TMA prerequisites (Hopper+), tensor map creation via cudaTensorMapEncodeTiled, initiating 1D TMA copy operations, synchronization with mbarrier, and complete code examples for loading and storing 1D arrays.
