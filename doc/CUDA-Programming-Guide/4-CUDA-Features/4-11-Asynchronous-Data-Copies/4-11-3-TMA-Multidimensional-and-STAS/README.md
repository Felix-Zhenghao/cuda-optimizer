# 4.11.2.2-3. TMA Multi-Dimensional Arrays and STAS

Covers TMA for multi-dimensional tiled tensor transfers, device-side tensor map encoding and modification at runtime, usage of modified tensor maps with fencing, creating template tensor map values via the Driver API, shared-memory bank swizzling to reduce conflicts, and the STAS (store-async) instruction for async shared-to-global memory stores.
