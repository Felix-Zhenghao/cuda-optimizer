# Overview and FP16/BF16 Forward

Introduces cuDNN's Scaled Dot Product Attention (SDPA) with FlashAttention-2. Covers the support matrix for Ampere through Blackwell, glossary, layout options (padded, ragged, interleaved), benchmarks, and the full FP16/BF16 forward pass API with configurable masking, dropout, and paged attention.
