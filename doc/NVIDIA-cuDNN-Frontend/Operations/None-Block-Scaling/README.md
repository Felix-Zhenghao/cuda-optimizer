# Block Scaling, Concatenate, Convolutions, Matmul, MoE Grouped Matmul

Merged documentation for five cuDNN Frontend operations. Block Scaling covers MXFP8/NVFP4 quantize and dequantize. Concatenate merges tensors along an axis. Convolutions provide fprop, dgrad, and wgrad. Matmul computes batched matrix multiplication. MoE Grouped Matmul supports Mixture-of-Experts gather/scatter modes.
