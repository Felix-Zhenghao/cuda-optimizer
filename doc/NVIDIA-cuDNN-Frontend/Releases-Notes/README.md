# Releases Notes

Release notes for cuDNN Frontend versions v1.17.0 through v1.22.0. Key highlights include open-source SDPA kernels for Blackwell/Hopper, PyTorch custom operator for SDPA, grouped GEMM fusions (SwiGLU, GLU, quantization), Native Sparse Attention, FP8/FP4 support, MoE workload APIs, and various performance improvements.
