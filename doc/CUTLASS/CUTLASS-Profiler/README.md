# CUTLASS Profiler

Command-line test and profiling environment for CUTLASS computations.

- **Profiler-Setup-and-Usage** -- Building the profiler, instantiation levels for Hopper/Blackwell, mixed dtype kernels, and CLI usage.
- **GEMM-and-Convolution-Reference** -- GEMM and Conv2d/Conv3d profiling arguments, examples, output formatting, and 3.x naming conventions.
