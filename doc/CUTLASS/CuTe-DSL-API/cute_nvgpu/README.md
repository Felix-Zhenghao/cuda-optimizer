# cute_nvgpu

- **Common**: Shared types: OpError, MmaUniversalOp, and field normalization helpers.
- **cpasync-submodule**: Asynchronous GMEM-to-SMEM copy operations via cp.async and TMA.
- **tcgen05-submodule**: Blackwell tensor memory copy and MMA operations.
- **warpgroup-submodule**: Hopper warpgroup-level F16/BF16 MMA operations.
- **warp-submodule**: Warp-level F16/BF16 MMA operations with PTX wrappers.
