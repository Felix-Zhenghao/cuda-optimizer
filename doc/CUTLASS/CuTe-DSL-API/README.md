# CuTe-DSL-API

- **changelog**: Version-by-version changelog of API additions, fixes, and deprecations.
- **cute**: Core CuTe DSL API modules for arch built-ins and runtime types.
- **cute_nvgpu**: GPU architecture-specific MMA and copy operation APIs.
- **pipeline**: Producer-consumer pipeline classes and synchronization primitives.
- **utils**: Architecture-specific utility functions for SM90 and SM100.
