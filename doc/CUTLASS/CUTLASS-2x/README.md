# CUTLASS-2x

Documentation for the CUTLASS 2.x API and its core abstractions.

- **GEMM-API** -- CUTLASS 2.x GEMM API covering device, threadblock, warp, thread, and instruction-level operations.
- **Layouts-and-Tensors** -- Layout concept, TensorRef, and TensorView design patterns for mapping logical indices to memory.
- **Tile-Iterator-Concepts** -- C++ concepts for tile iterators including readable, writeable, and random access variants.
- **Utilities** -- Utility classes for tensor allocation, initialization, reference implementations, and synclog debugging.
