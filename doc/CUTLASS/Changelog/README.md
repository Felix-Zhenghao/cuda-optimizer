# Changelog

Release history for the CUTLASS library across major version lines.

- **CUTLASS-1x-2x-Changelog** -- Release notes for CUTLASS versions 1.x through 2.11, covering early features through Hopper support.
- **CUTLASS-3x-Changelog** -- Release notes for CUTLASS 3.x versions including Hopper and Blackwell kernel support.
- **CUTLASS-4x-Changelog** -- Release notes for CUTLASS 4.x featuring CuTe DSL, Python 3.14 support, and Blackwell enhancements.
