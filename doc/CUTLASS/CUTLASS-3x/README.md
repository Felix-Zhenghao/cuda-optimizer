# CUTLASS-3x

Documentation for the CUTLASS 3.x API, its design philosophy, and migration from 2.x.

- **Design** -- Design goals and architectural changes in CUTLASS 3.0 including CuTe adoption and tag-dispatch policies.
- **GEMM-API** -- The CUTLASS 3.0 GEMM API hierarchy: Device, Kernel, Collective, Tiled MMA/Copy, and Atom layers.
- **GEMM-Backwards-Compatibility** -- How CUTLASS 3.0 maintains backwards compatibility with 2.x APIs and migration guidance.
