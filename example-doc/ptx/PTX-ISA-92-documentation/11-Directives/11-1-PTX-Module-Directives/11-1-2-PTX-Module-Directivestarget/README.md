# 11.1.2: PTX Module Directives: .target

Specifies the target architecture and platform options for a PTX module. Covers all SM architectures from sm_10 through sm_121, including architecture-specific ("a") and family-specific ("f") suffixes. Also documents texturing mode, debug, and map_f64_to_f32 platform options. The onion-layer compatibility model is explained.
