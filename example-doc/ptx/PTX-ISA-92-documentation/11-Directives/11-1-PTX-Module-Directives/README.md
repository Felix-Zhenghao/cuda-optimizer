# 11.1: PTX Module Directives

- **11-1-1-PTX-Module-Directivesversion** -- .version directive specifying the PTX ISA version number for the module.
- **11-1-2-PTX-Module-Directivestarget** -- .target directive specifying target SM architecture and platform options.
- **11-1-3-PTX-Module-Directivesaddress_size** -- .address_size directive specifying 32-bit or 64-bit addressing mode.
