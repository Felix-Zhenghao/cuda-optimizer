# 11.4: Performance-Tuning Directives

Covers directives for performance optimization: .maxnreg (max registers per thread), .maxntid/.reqntid (thread block size), .minnctapersm/.maxnctapersm (CTAs per SM), .noreturn (non-returning functions), .pragma (backend compiler hints), and .abi_preserve/.abi_preserve_control (callee-save register counts). Includes deprecated .maxnctapersm replaced by .minnctapersm.
