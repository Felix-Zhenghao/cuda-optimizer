# 11.3.1-11.3.2: Control Flow Directives: .branchtargets and .calltargets

Documents .branchtargets for declaring potential branch targets used with brx.idx instructions, and .calltargets for declaring potential indirect call targets. Both associate a label with a list of targets. Supports compact shorthand syntax for label ranges. Both introduced in PTX ISA 2.1, require sm_20+.
