# 11.3.3: Control Flow Directives: .callprototype

Declares a prototype for indirect function calls without naming a specific function. Associates the prototype with a label for use in indirect call instructions. Supports .noreturn, .abi_preserve, and .abi_preserve_control directives. Parameters can use register or .param state spaces. Introduced in PTX ISA 2.1, requires sm_20+.
