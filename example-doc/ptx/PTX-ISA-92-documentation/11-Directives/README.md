# 11. Directives

- **11-1-PTX-Module-Directives** -- Module-level directives: .version, .target, .address_size.
- **11-2-Specifying-Kernel-Entry-Points-and-Functions** -- Kernel and function definition directives: .entry, .func, .alias.
- **11-3-Control-Flow-Directives** -- Indirect branch/call target declarations and call prototypes.
- **11-4-Performance-Tuning-Directives** -- Register limits, thread counts, CTA tuning, pragma, and ABI preservation.
- **11-5-Debugging-Directives** -- DWARF debug information, source file and location mapping.
- **11-6-Linking-Directives** -- Symbol visibility and linkage: .extern, .visible, .weak, .common.
- **11-7-Cluster-Dimension-Directives** -- Cluster configuration: CTA count, explicit launch, max rank.
- **11-8-Miscellaneous-Directives** -- .blocksareclusters for cluster-based grid launch configuration.
