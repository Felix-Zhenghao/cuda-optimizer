# 11.5.2: Debugging Directives: .section

Defines PTX debug sections containing DWARF data. Supports .b8, .b16, .b32, .b64 data formats, labels, label arithmetic (addition and difference), and negative values. Replaces the deprecated @@DWARF syntax. Introduced in PTX ISA 2.0 with progressive enhancements through version 7.5.
