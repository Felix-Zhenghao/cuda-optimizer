# 11.5: Debugging Directives

- **11-5-1-Debugging-Directivesdwarf** -- Deprecated @@DWARF syntax for embedding DWARF debug information.
- **11-5-2-Debugging-Directivessection** -- .section directive for defining DWARF debug data sections.
- **11-5-3-Debugging-Directivesfile** -- .file directive associating source filenames with indices.
- **11-5-4-Debugging-Directivesloc** -- .loc directive mapping PTX instructions to source locations.
