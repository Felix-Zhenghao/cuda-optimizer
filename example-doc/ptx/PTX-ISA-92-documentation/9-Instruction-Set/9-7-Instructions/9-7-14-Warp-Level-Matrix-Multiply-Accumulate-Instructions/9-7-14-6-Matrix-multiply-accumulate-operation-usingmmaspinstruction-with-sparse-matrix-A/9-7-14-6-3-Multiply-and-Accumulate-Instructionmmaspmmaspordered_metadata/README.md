# 9.7.14.6.3. Multiply-and-Accumulate Instruction: mma.sp / mma.sp::ordered_metadata

Documents the `mma.sp` and `mma.sp::ordered_metadata` instructions for sparse matrix multiply-accumulate. Provides full syntax for all type variants. The sparse selector operand identifies which threads supply metadata. Ordered metadata variant enables compiler-optimized metadata reuse. Lists PTX ISA/SM requirements.
