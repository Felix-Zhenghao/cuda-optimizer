# 9.7.14.6.2.6. Matrix Fragments for sparse mma.m16n8k64 with .u8/.s8/.e4m3/.e5m2 Type

Describes per-thread fragment distribution for sparse `mma.m16n8k64` with u8/s8/e4m3/e5m2/e3m2/e2m3/e2m1 types. Uses 2:4 structured sparsity on matrix A. Includes layouts for compressed A, full B, s32 accumulator C/D, and sparsity metadata.
