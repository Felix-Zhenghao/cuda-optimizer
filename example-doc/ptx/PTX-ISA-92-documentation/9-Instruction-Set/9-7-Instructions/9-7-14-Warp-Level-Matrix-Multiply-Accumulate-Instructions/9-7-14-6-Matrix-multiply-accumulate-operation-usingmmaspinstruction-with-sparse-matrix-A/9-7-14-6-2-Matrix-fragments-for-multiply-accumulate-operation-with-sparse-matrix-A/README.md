# 9.7.14.6.2. Matrix Fragments for Multiply-Accumulate with Sparse Matrix A

- **9.7.14.6.2.1. Sparse mma.m16n8k16 f16/bf16** -- Fragment layout for sparse m16n8k16 with f16/bf16.
- **9.7.14.6.2.2. Sparse mma.m16n8k32 f16/bf16** -- Fragment layout for sparse m16n8k32 with f16/bf16.
- **9.7.14.6.2.3. Sparse mma.m16n8k16 tf32** -- Fragment layout for sparse m16n8k16 with tf32.
- **9.7.14.6.2.4-5. Sparse mma.m16n8k8/k32 tf32/int** -- Fragment layouts for sparse m16n8k8 tf32 and m16n8k32 integer.
- **9.7.14.6.2.6. Sparse mma.m16n8k64 u8/s8/fp8** -- Fragment layout for sparse m16n8k64 with 8-bit types.
- **9.7.14.6.2.7. Sparse mma.m16n8k64 u4/s4** -- Fragment layout for sparse m16n8k64 with 4-bit integer.
- **9.7.14.6.2.8. Sparse mma.m16n8k128 u4/s4** -- Fragment layout for sparse m16n8k128 with 4-bit integer.
