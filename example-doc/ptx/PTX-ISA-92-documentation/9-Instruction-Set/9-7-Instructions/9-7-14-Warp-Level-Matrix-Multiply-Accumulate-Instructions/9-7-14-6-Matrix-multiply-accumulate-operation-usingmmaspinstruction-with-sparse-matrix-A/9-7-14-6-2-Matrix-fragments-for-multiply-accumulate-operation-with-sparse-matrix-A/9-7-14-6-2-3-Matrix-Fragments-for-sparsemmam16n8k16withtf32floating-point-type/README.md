# 9.7.14.6.2.3. Matrix Fragments for sparse mma.m16n8k16 with .tf32 Floating Point Type

Describes per-thread fragment distribution for sparse `mma.m16n8k16` with tf32 type. Matrix A uses 2:4 structured sparsity. Includes layouts for compressed A, full B, f32 accumulator C/D, and sparsity metadata across warp threads.
