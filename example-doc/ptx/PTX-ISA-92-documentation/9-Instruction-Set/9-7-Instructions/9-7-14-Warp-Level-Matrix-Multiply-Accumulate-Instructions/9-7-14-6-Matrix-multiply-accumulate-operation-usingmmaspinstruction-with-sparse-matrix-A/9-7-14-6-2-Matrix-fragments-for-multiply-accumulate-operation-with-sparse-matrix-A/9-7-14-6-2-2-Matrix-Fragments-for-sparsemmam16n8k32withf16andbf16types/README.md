# 9.7.14.6.2.2. Matrix Fragments for sparse mma.m16n8k32 with .f16 and .bf16 Types

Describes per-thread fragment distribution for sparse `mma.m16n8k32` with f16/bf16 types. Includes fragment layouts for compressed matrix A (2:4 sparsity), full matrix B, accumulator C/D, and sparsity metadata registers distributed across the warp.
