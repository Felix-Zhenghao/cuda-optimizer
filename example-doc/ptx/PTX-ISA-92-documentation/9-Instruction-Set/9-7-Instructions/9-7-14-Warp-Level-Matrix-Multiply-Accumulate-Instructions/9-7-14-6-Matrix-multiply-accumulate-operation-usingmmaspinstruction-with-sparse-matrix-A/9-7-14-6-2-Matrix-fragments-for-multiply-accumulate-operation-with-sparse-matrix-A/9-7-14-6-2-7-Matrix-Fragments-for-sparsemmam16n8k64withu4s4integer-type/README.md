# 9.7.14.6.2.7. Matrix Fragments for sparse mma.m16n8k64 with .u4/.s4 Integer Type

Describes per-thread fragment distribution for sparse `mma.m16n8k64` with u4/s4 sub-byte integer type. Uses 4:8 structured sparsity on matrix A. Includes layouts for compressed A, full B, s32 accumulator C/D, and sparsity metadata.
