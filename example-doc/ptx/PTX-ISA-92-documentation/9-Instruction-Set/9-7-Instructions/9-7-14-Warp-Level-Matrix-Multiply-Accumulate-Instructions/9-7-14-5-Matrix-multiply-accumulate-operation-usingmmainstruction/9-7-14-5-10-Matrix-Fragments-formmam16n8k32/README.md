# 9.7.14.5.10. Matrix Fragments for mma.m16n8k32

Describes fragment distribution for `mma.m16n8k32` MMA operation. Covers integer types (u8, s8), sub-byte types (u4, s4), and alternate floating-point types (e4m3, e5m2, e3m2, e2m3, e2m1). Each thread holds b32 register fragments containing packed elements. Includes fragment layout tables per type.
