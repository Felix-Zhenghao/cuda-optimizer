# 9.7.14.5.12. Matrix Fragments for mma.m16n8k128

Describes fragment distribution for `mma.m16n8k128` MMA operation with single-bit (b1) type and s32 accumulator. Each thread holds specific b32 register fragments. Also covers the m16n8k128 shape for e2m1 type with block scaling using ue8m0/ue4m3 scale factors.
