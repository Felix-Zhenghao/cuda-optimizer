# 9.7.14.5.14. Multiply-and-Accumulate Instruction: mma

Documents the `mma` instruction performing D = A * B + C at warp level. Provides full syntax for all type variants: f16, bf16, tf32, f64, integer, sub-byte, single-bit, and alternate FP formats with optional block scaling (.kind qualifiers). Includes semantics, operand constraints, and PTX ISA version requirements.
