# 9.7.14.5.9. Matrix Fragments for mma.m16n8k16 with Integer Type

Describes fragment distribution for `mma.m16n8k16` with integer types (u8, s8) and alternate floating-point types (e4m3, e5m2, e3m2, e2m3, e2m1). Elements of A, B, C, D distributed across warp threads with s32 accumulator. Includes per-thread register fragment layouts.
