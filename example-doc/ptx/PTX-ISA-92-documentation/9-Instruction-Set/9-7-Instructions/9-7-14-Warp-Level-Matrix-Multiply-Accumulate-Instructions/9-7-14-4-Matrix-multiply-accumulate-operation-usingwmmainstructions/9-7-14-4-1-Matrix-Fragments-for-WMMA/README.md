# 9.7.14.4.1. Matrix Fragments for WMMA

Describes how matrix fragments are distributed across threads in a warp for WMMA operations. Each thread holds an architecture-dependent fragment. Lists per-thread register counts for matrices A, B, C, and D across all supported shapes (m16n16k16, m8n32k16, m32n8k16, m16n16k8, m8n8k32, m8n8k128) and data types.
