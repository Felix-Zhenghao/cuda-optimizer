# 9.7.14.4.3. Warp-level Matrix Load Instruction: wmma.load

Documents the `wmma.load` instruction that collectively loads matrix fragments from memory into registers across a warp. Supports f16, bf16, tf32, integer, and sub-byte types with row/column layouts. Requires 128-bit aligned addresses. Includes syntax, operand descriptions, state space qualifiers, and PTX ISA version requirements.
