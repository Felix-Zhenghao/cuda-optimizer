# 9.7.14.2. Matrix Data-types

Describes data types for warp-level MMA operands. Floating-point types include f16, bf16, tf32, and f64. Integer types include u8, s8, u4, s4, and single-bit b1. Alternate floating-point formats include e4m3, e5m2, e3m2, e2m3, and e2m1. Specifies allowed type combinations for multiplicands A/B and accumulators C/D.
