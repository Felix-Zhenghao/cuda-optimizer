# 9.7.1.14--9.7.1.23 Integer Arithmetic Instructions

Documents PTX integer bit-manipulation and specialized instructions: `popc` (population count), `clz` (count leading zeros), `bfind` (find most significant non-sign bit), `fns` (find n-th set bit), `brev` (bit reverse), `bfe` (bit field extract), `bfi` (bit field insert), `szext` (sign/zero extend), `bmsk` (bitmask generation), and `dp4a` (four-way byte dot product-accumulate).
