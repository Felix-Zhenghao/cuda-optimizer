# 9.7.1.1 Integer Arithmetic Instructions: add

Documents the PTX `add` instruction for integer addition. Covers signed/unsigned 16/32/64-bit types plus packed SIMD variants (u16x2, s16x2, u8x4, s8x4). Includes saturation modifier, parallel vector semantics, and target architecture requirements (sm_90+ for SIMD, sm_120f for saturating SIMD).
