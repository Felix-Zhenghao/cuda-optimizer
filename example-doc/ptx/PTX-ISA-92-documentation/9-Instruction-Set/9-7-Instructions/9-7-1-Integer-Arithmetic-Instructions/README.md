# 9.7.1 Integer Arithmetic Instructions

- **9-7-1-1-Integer-Arithmetic-Instructionsadd**: `add` instruction for integer addition with SIMD variants.
- **9-7-1-2-to-9-7-1-11-Integer-Arithmetic-Instructions**: `sub`, `mul`, `mad`, `mul24`, `mad24`, `sad`, `div`, `rem`, `abs`, `neg` instructions.
- **9-7-1-12-Integer-Arithmetic-Instructionsmin**: `min` instruction with SIMD and relu support.
- **9-7-1-13-Integer-Arithmetic-Instructionsmax**: `max` instruction with SIMD and relu support.
- **9-7-1-14-to-9-7-1-23-Integer-Arithmetic-Instructions**: Bit manipulation (`popc`, `clz`, `bfind`, `brev`, `bfe`, `bfi`, etc.) and `dp4a`.
- **9-7-1-24-Integer-Arithmetic-Instructionsdp2a**: `dp2a` two-way dot product-accumulate.
