# 9.7.1.2--9.7.1.11 Integer Arithmetic Instructions

Documents PTX integer arithmetic instructions: `sub` (subtract with SIMD u8x4/s8x4), `mul` (multiply with hi/lo/wide modes), `mad` (multiply-add), `mul24`/`mad24` (24-bit multiply variants), `sad` (sum of absolute differences), `div` (integer divide), `rem` (remainder), `abs` (absolute value), and `neg` (negate with s8x4 SIMD support).
