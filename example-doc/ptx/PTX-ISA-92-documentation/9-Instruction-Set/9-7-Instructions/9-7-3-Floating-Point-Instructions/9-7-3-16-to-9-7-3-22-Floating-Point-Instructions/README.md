# 9.7.3.16--9.7.3.22 Floating Point Instructions

Documents transcendental and special floating-point instructions: `rsqrt` (reciprocal square root, plus ftz.f64 variant), `sin` (sine approximation), `cos` (cosine approximation), `lg2` (base-2 logarithm), `ex2` (base-2 exponential), and `tanh` (hyperbolic tangent, sm_75+). All use fast approximations with documented error bounds.
