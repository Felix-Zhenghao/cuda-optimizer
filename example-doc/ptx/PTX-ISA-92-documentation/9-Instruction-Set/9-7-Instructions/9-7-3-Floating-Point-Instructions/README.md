# 9.7.3 Floating Point Instructions

- **9-7-3-1-to-9-7-3-2**: `testp` (test FP properties) and `copysign` (copy sign bit).
- **9-7-3-3-Floating-Point-Instructionsadd**: Floating-point `add` with f32, f32x2, f64 support.
- **9-7-3-4-Floating-Point-Instructionssub**: Floating-point `sub` with f32, f32x2, f64 support.
- **9-7-3-5-Floating-Point-Instructionsmul**: Floating-point `mul` with f32, f32x2, f64 support.
- **9-7-3-6-Floating-Point-Instructionsfma**: Fused multiply-add `fma` for f32, f32x2, f64.
- **9-7-3-7-Floating-Point-Instructionsmad**: Multiply-add `mad` for f32, f64.
- **9-7-3-8-Floating-Point-Instructionsdiv**: Floating-point `div` with approx, full, and IEEE modes.
- **9-7-3-9-to-9-7-3-10**: `abs` and `neg` for floating-point types.
- **9-7-3-11-Floating-Point-Instructionsmin**: `min` with NaN and xorsign.abs modifiers.
- **9-7-3-12-Floating-Point-Instructionsmax**: `max` with NaN and xorsign.abs modifiers.
- **9-7-3-13-to-9-7-3-14**: `rcp` reciprocal (approx and IEEE) plus f64 gross approximation.
- **9-7-3-15-Floating-Point-Instructionssqrt**: `sqrt` with approx and IEEE rounding modes.
- **9-7-3-16-to-9-7-3-22**: Transcendentals: `rsqrt`, `sin`, `cos`, `lg2`, `ex2`, `tanh`.
