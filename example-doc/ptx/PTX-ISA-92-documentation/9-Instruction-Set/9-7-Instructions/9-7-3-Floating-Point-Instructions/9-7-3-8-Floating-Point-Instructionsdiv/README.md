# 9.7.3.8 Floating Point Instructions: div

Documents PTX floating-point `div` with three modes: `div.approx.f32` (fast, max 2 ULP error), `div.full.f32` (full-range approximate, max 2 ULP), and `div.rnd` (IEEE 754 compliant with explicit rounding). Covers f32 and f64 types with subnormal handling.
