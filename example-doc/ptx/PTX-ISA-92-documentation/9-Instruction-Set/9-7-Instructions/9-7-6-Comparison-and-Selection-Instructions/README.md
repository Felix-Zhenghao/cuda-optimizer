# 9.7.6. Comparison and Selection Instructions

- **9-7-6-1 set** -- Compare two values, optionally combine with predicate, write numeric true/false result.
- **9-7-6-2 setp** -- Compare two values, write result to predicate registers with optional Boolean combine.
- **9-7-6-3-to-4 selp, slct** -- Conditional selection based on predicate (selp) or operand sign (slct).
