# 9.7.16.3.3. Canonical Layouts

Expresses tcgen05 shared memory layouts in CuTe layout notation. Lists canonical layouts for K-major and non-K-major orientations across swizzling modes (none, 32B, 64B, 128B). Provides layout expressions with and without swizzling for 8-bit, 16-bit, and 32-bit element sizes.
