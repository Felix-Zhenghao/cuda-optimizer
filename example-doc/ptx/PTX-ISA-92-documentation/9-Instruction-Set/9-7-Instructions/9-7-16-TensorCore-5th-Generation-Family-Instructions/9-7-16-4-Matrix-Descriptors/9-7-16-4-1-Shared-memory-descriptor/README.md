# 9.7.16.4.1. Shared Memory Descriptor

Describes the 64-bit shared memory descriptor for tcgen05 operations. Contains start address (bits 0-13), leading dimension stride (bits 16-29), stride dimension byte offset (bits 32-45), base offset (bits 49-52), and swizzling mode (bits 62-63). Byte address mode for stride supported on sm_103a.
