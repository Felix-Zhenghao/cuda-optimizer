# 9.7.16.10.9.1. TensorCore 5th Generation Instructions: tcgen05.mma

Documents `tcgen05.mma` performing 5th-generation matrix multiply-accumulate. Supports floating-point (f16, bf16, tf32), integer, and alternate FP types with optional block scaling. Matrix D in Tensor Memory, A in Tensor/shared memory, B in shared memory. Includes full syntax, semantics, and PTX ISA 8.6+ requirements.
