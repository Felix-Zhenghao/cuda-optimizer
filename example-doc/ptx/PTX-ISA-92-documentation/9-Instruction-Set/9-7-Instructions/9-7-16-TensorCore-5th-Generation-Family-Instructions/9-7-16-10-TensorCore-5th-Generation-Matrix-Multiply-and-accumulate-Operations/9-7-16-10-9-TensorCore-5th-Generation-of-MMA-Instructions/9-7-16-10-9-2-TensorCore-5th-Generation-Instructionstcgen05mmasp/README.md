# 9.7.16.10.9.2. TensorCore 5th Generation Instructions: tcgen05.mma.sp

Documents `tcgen05.mma.sp` for sparse MMA with structured sparsity on matrix A. Supports floating-point and alternate FP types with optional block scaling. Matrix A stores only non-zero elements in Tensor Memory with metadata. Includes full syntax and PTX ISA 8.6+ requirements.
