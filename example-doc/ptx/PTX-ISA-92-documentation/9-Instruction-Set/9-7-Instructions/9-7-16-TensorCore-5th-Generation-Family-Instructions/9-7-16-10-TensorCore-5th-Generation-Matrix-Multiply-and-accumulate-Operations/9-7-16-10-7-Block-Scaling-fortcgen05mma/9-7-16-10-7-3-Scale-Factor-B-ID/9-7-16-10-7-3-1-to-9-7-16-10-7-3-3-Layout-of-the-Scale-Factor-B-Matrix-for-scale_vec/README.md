# 9.7.16.10.7.3.1-3. Layout of Scale Factor B Matrix for scale_vec::1X/2X/4X

Defines shared memory layout of scale factor B matrix for tcgen05 block scaling with scale_vec::1X (block32, K=32/K=64), scale_vec::2X (block16, K=32/K=64), and scale_vec::4X (block16, K=64). Scale factors stored in 4-byte aligned rows.
