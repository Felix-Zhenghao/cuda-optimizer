# 9.7.16.10.7.2. Scale Factor A

Defines layout of scale factor A matrix in Tensor Memory for tcgen05 block scaling. One scale factor per row of A with block size 32. Scale factors stored in 1-byte aligned sub-columns. Includes diagrams for scale_vec::1X/block32 with K=32/K=64, and scale_vec::2X/block16 with K=32/K=64.
