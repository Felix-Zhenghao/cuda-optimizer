# 9.7.16.10.7.1. Valid Combinations of scale_vectorsize with Types and MMA Kind

Lists valid combinations of `.scale_vectorsize` (1X, 2X, 4X) with data types and MMA kinds for tcgen05 block scaling. Scale_A and scale_B matrix shapes depend on the vector size. Supported for kind::f16, kind::tf32, kind::f8f6f4, kind::mxf4, and kind::mxf4nvf4.
