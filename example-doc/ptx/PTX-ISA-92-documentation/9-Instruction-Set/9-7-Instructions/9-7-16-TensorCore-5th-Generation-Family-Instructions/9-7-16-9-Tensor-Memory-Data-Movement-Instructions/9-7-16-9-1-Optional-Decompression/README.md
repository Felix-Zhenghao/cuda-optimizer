# 9.7.16.9.1. Optional Decompression

Describes optional decompression during `tcgen05.cp` from shared to Tensor Memory. Supports 4-bit to 8-bit FP decompression (16 elements of 4-bits + 8 bytes padding become 16 elements of 8-bits) and 6-bit to 8-bit decompression (16 elements of 6-bits + 4 bytes padding become 16 elements of 8-bits).
