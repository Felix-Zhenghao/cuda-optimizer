# 9.7.16.2.3. Data Movement Shape

Defines shapes for tcgen05 load, store, and copy operations. Shapes include 32x32b, 16x32bx2, 16x128b, 16x256b, 128x256b, and 32x128b. Lists per-thread register fragment layouts and element distributions for each shape. Used by `tcgen05.ld`, `tcgen05.st`, and `tcgen05.cp` instructions.
