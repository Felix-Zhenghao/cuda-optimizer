# 9.7.13.15.1-12. mbarrier Object Fundamentals

Covers mbarrier object specification: 8-byte aligned .b64 in shared memory; tracks phase, pending arrivals, expected arrivals, and tx-count. Describes lifecycle (init, use, invalidate), phase completion requirements, arrive-on and expect-tx/complete-tx operations, shared memory support, and init/inval/expect_tx/complete_tx instructions.
