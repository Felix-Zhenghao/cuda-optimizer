# 9.7.8. Logic and Shift Instructions

- **9-7-8-1-to-5 and, or, xor, not, cnot** -- Basic bitwise logic operations and logical negation.
- **9-7-8-6 lop3** -- Arbitrary 3-input logical operation using 8-bit lookup table encoding.
- **9-7-8-7 shf** -- Funnel shift for 64-bit concatenated values, supports rotate operations.
- **9-7-8-8-to-9 shl, shr** -- Bit shift left (zero-fill) and right (sign/zero-fill) instructions.
