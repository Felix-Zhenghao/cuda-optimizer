# 9.7.8.1-5. Logic and Shift Instructions: and, or, xor, not, cnot

Covers five basic bitwise logic instructions. `and`, `or`, `xor` compute bitwise operations on two operands; `not` performs bitwise negation (one's complement); `cnot` performs C-style logical negation (returns 1 if input is zero, else 0). All support predicate and bit-size types (.b16, .b32, .b64). Introduced in PTX ISA 1.0, supported on all architectures.
