# 9.7.15.3-4. Matrix Data-types and Block Scaling

Describes data types for warpgroup-level MMA operands including f16, bf16, tf32, integer, sub-byte, and alternate FP formats. Also covers block scaling with `.kind` qualifiers (mxf8f6f4, mxf4, mxf4nvf4) that compute `D = (A * scale_A) * (B * scale_B) + C`.
