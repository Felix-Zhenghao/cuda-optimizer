# 9.7 Instructions

- **Integer-Arithmetic-Instructions** — Add, subtract, multiply, divide, remainder, abs, min, max, popcount, and dot-product instructions for integers.
- **Extended-Precision-Integer-Arithmetic-Instructions** — Carry-flag arithmetic (add.cc, sub.cc, mad.cc, madc) for multi-word precision integer operations.
- **Floating-Point-Instructions** — Full set of FP32/FP64 arithmetic: add, sub, mul, fma, div, rcp, sqrt, trig, and transcendentals.
- **Half-Precision-Floating-Point-Instructions** — FP16/BF16 arithmetic including add, sub, mul, fma, min, max, tanh, and ex2 instructions.
- **Mixed-Precision-Floating-Point-Instructions** — Mixed-precision add, sub, fma operating across different floating-point widths (e.g., FP16 inputs, FP32 output).
- **Comparison-and-Selection-Instructions** — Set predicates and select values based on comparisons; covers setp, selp, set instructions for various types.
- **Half-Precision-Comparison-Instructions** — Half-precision setp and set instructions for FP16/BF16 comparison operations.
- **Logic-and-Shift-Instructions** — Bitwise and, or, xor, not, shift left/right, and leading-zero count (clz, brev, popc) instructions.
- **Data-Movement-and-Conversion-Instructions** — Load, store, move, convert, prefetch, and async copy instructions across state spaces and types.
- **Texture-Instructions** — Texture fetch (tex), texture gradient (tld4), texture query (txq) for sampler-based texture operations.
- **Surface-Instructions** — Surface load (suld), store (sust), query (suq) for bindless and bound surface memory access.
- **Control-Flow-Instructions** — Branch (bra), call, return, exit, and indirect branch instructions for program control flow.
- **Parallel-Synchronization-and-Communication-Instructions** — Barriers, atomics, reductions, membar, fence, vote, match, redux, mbarrier, and elect instructions.
- **Warp-Level-Matrix-Multiply-Accumulate-Instructions** — wmma and mma instructions for warp-cooperative matrix operations on Tensor Cores (Volta through Ampere).
- **Asynchronous-Warpgroup-Level-Matrix-Multiply-Accumulate-Instructions** — wgmma.mma_async for asynchronous warpgroup-level matrix operations on Hopper+ Tensor Cores.
- **TensorCore-5th-Generation-Family-Instructions** — tcgen05 instruction family for 5th-gen Tensor Core: MMA, load/store, copy, shift, alloc, fence.
- **Stack-Manipulation-Instructions** — stacksave, stackrestore, and alloca for per-thread dynamic stack management.
- **Video-Instructions** — Scalar and SIMD video instructions (vadd, vsub, vmad, vset, etc.) for byte/half-word packed operations.
- **Miscellaneous-Instructions** — brkpt, nanosleep, pmevent, trap, and setmaxnreg utility instructions.
