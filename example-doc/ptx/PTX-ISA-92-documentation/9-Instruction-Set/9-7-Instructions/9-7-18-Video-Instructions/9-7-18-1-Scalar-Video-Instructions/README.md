# 9.7.18.1. Scalar Video Instructions

- **vadd, vsub, vabsdiff, vmin, vmax, vshl, vshr** -- Scalar 32-bit integer arithmetic and shift operations on byte/half-word/word with optional saturation and secondary ops.
- **vmad** -- Scalar integer multiply-accumulate with optional negation, plus-one mode, and right-shift scaling.
- **vset** -- Scalar integer byte/half-word/word comparison producing unsigned results with optional secondary operations.
