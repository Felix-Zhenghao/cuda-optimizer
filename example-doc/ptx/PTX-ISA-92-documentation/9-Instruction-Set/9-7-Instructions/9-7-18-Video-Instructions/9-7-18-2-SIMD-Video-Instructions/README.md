# 9.7.18.2. SIMD Video Instructions

- **vadd2, vsub2, vavrg2, vabsdiff2, vmin2, vmax2** -- Dual half-word SIMD arithmetic with optional saturation, merge, or accumulate.
- **vset2** -- Dual half-word SIMD comparison producing unsigned results with merge or accumulate.
- **vadd4, vsub4, vavrg4, vabsdiff4, vmin4, vmax4** -- Quad byte SIMD arithmetic with optional saturation, merge, or accumulate.
- **vset4** -- Quad byte SIMD comparison producing unsigned results with merge or accumulate.
