# 9.7.4 Half Precision Floating Point Instructions

- **9-7-4-1-...add**: Half-precision `add` for f16/bf16 scalar and SIMD.
- **9-7-4-2-...sub**: Half-precision `sub` for f16/bf16 scalar and SIMD.
- **9-7-4-3-...mul**: Half-precision `mul` for f16/bf16 scalar and SIMD.
- **9-7-4-4-...fma**: Half-precision `fma` with relu and oob modifiers.
- **9-7-4-5-to-9-7-4-6**: `neg` and `abs` for f16/bf16.
- **9-7-4-7-...min**: `min` with NaN and xorsign.abs support.
- **9-7-4-8-...max**: `max` with NaN and xorsign.abs support.
- **9-7-4-9-...tanh**: Approximate hyperbolic tangent.
- **9-7-4-10-...ex2**: Approximate base-2 exponential.
