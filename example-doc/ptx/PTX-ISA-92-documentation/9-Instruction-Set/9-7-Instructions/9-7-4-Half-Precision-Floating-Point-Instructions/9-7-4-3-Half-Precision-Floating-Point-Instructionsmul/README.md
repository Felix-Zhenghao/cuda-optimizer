# 9.7.4.3 Half Precision Floating Point Instructions: mul

Documents half-precision `mul` for f16, f16x2, bf16, and bf16x2 types. Supports SIMD packed operations, flush-to-zero, and saturation modifiers for f16 variants. bf16 support requires sm_90+. Mul/add sequences may be fused into FMA by the optimizer.
