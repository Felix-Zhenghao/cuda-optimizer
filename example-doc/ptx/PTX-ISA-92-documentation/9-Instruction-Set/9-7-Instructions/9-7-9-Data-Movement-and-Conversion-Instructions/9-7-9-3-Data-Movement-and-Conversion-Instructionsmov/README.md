# 9.7.9.3. Data Movement and Conversion Instructions: mov

The `mov` instruction copies a value to a register from another register, special register, immediate, variable address, or function address. For variables in .const, .global, .local, and .shared spaces, mov provides the non-generic state-space address. Supports all predicate, bit-size, integer, and float types. Introduced in PTX ISA 1.0.
