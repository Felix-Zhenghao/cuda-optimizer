# 9.7.9.25.4. Bulk Asynchronous Copy Instructions

- **9-7-9-25-4-1 cp.async.bulk** -- Asynchronous bulk copy between state spaces with multicast support.
- **9-7-9-25-4-2 cp.reduce.async.bulk** -- Asynchronous bulk reduction between state spaces.
- **9-7-9-25-4-3 cp.async.bulk.prefetch** -- Hint to prefetch global data into L2 cache.
- **9-7-9-25-4-4 multimem.cp.async.bulk** -- Bulk copy to all GPUs via multimem addresses.
- **9-7-9-25-4-5 multimem.cp.reduce.async.bulk** -- Bulk reduction to all GPUs via multimem addresses.
