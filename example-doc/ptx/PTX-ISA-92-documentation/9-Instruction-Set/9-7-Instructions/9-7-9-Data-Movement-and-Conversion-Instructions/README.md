# 9.7.9. Data Movement and Conversion Instructions

- **9-7-9-1 Cache Operators** -- Cache operators (.ca, .cg, .cs, .lu, .cv, .wb, .wt) for ld/st.
- **9-7-9-2 Cache Eviction Priority Hints** -- L1/L2 eviction priority qualifiers and cache hints.
- **9-7-9-3 mov** -- Move values between registers, special registers, addresses, and immediates.
- **9-7-9-4 mov (vector)** -- Pack/unpack vector elements to/from scalar registers.
- **9-7-9-5 shfl (deprecated)** -- Deprecated warp shuffle; replaced by shfl.sync.
- **9-7-9-6 shfl.sync** -- Warp-level register data exchange with explicit thread synchronization.
- **9-7-9-7 prmt** -- Byte permute from two 32-bit registers into one destination.
- **9-7-9-8 ld** -- Load from addressable state spaces with ordering/scope/cache control.
- **9-7-9-9 ld.global.nc** -- Load via non-coherent cache for read-only global data.
- **9-7-9-10 ldu** -- Load uniform read-only data common across warp threads.
- **9-7-9-11 st** -- Store to addressable state spaces with ordering/scope/cache control.
- **9-7-9-12 st.async** -- Non-blocking async store with mbarrier or release semantics.
- **9-7-9-13 st.bulk** -- Bulk zero-initialization of shared memory regions.
- **9-7-9-14 multimem.ld_reduce, st, red** -- Multi-GPU memory load-reduce, store, and reduce.
- **9-7-9-15 prefetch, prefetchu** -- Cache line prefetch to L1/L2 or uniform cache.
- **9-7-9-16-to-17 applypriority, discard** -- Cache priority application and data discard.
- **9-7-9-18 createpolicy** -- Create cache eviction policies (range/fraction-based).
- **9-7-9-19 isspacep** -- Query if generic address falls in a specified state space.
- **9-7-9-20 cvta** -- Convert between state-space and generic addresses.
- **9-7-9-21 cvt** -- Type conversion with rounding, saturation, and packed formats.
- **9-7-9-22 cvt.pack** -- Convert and pack two integers into smaller packed types.
- **9-7-9-23-to-24 mapa, getctarank** -- Cluster-level shared memory address mapping.
- **9-7-9-25 Asynchronous copy** -- Async copy/reduce for bulk, tensor, and non-bulk operations.
- **9-7-9-26 tensormap.replace** -- Modify fields of tensor-map objects in memory.
