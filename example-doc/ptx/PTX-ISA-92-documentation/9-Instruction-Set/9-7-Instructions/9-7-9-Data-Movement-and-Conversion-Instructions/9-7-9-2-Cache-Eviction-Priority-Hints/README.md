# 9.7.9.2. Cache Eviction Priority Hints

Documents cache eviction priority hints for memory instructions, allowing control over L1 and L2 cache eviction behavior. Includes eviction priority qualifiers (.evict_normal, .evict_first, .evict_last, .evict_unchanged, .no_allocate) and cache hint mechanisms (.L2::cache_hint) for fine-grained cache management. Used with load, store, and prefetch operations for performance optimization.
