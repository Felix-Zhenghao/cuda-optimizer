# 9. Instruction Set

- **9-1-to-9-2-Format-and-Semantics** — Describes PTX instruction format, optional guard predicates, opcode mnemonics, and operand notation conventions.
- **9-3-Predicated-Execution** — Predicate registers and per-instruction predication for conditional execution without branching.
- **9-4-Type-Information-for-Instructions-and-Operands** — Type-checking rules, operand size compatibility, and type conversion for PTX instructions.
- **9-5-to-9-6-Divergence-of-Threads** — Thread divergence in branches/loops, warp-level reconvergence, and uniform/divergent condition semantics.
- **9-7-Instructions** — Complete reference for all PTX instructions: arithmetic, logic, data movement, control flow, synchronization, matrix, and more.
