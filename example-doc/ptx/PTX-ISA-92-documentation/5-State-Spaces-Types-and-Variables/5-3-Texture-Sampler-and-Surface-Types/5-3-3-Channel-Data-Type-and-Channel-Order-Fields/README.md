# 5.3.3. Channel Data Type and Channel Order Fields

Lists the OpenCL 1.0 enumeration values for channel_data_type (CL_SNORM_INT8 through CL_FLOAT, hex codes 0x10D0-0x10DE) and channel_order (CL_R through CL_LUMINANCE, hex codes 0x10B0-0x10B9) used to configure texture and surface properties in PTX.
