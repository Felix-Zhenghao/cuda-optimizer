# 5.2.5. Packed Data Types

Covers packed floating-point types (.f16x2, .bf16x2, .e4m3x2, .e5m2x4, etc.), packed integer types (.u16x2, .s16x2, .u8x4, .s8x4), and packed fixed-point type (.s2f6x2). Details which register variable types (.b16, .b32, .b64) are required for each packed format and their usage as instruction types rather than fundamental types.
