# Fundamental Types (5.2.1 to 5.2.2)

Merged from: 5-2-1-Fundamental-Types to 5-2-2-Restricted-Use-of-Sub-Word-Sizes

Lists PTX fundamental type specifiers: signed/unsigned integers (.s8-.s64, .u8-.u64), floating-point (.f16, .f16x2, .f32, .f64), bit-size (.b8-.b128), and predicate (.pred). Explains type compatibility rules and restrictions on sub-word sizes (.u8, .s8, .b8) to specific instructions like ld, st, and cvt.
