# 5.2. Types

- **5-2-1-to-5-2-2-Fundamental-Types** -- Fundamental type specifiers (integers, floats, bits, predicates) and sub-word restrictions.
- **5-2-3-Alternate-Floating-Point-Data-Formats** -- Non-fundamental FP formats: bf16, e4m3, e5m2, tf32, e2m1, and others.
- **5-2-4-Fixed-point-Data-format** -- The s2f6 8-bit signed fixed-point format with 6 fractional bits.
- **5-2-5-Packed-Data-Types** -- Packed floating-point, integer, and fixed-point data types for SIMD-style operations.
