# 5.2.4. Fixed-point Data Format

Describes the s2f6 fixed-point data format: an 8-bit signed 2's complement number with 2 sign-integer bits and 6 fractional bits (form xx.xxxxxx). Covers the value encoding formula (s8 * 2^-6) with positive max of 1.984375 and negative max of -2.0. Does not support infinity or NaN.
