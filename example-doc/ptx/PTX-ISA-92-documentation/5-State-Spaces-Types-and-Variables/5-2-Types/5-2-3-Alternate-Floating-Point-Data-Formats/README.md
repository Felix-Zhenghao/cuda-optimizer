# 5.2.3. Alternate Floating-Point Data Formats

Describes non-fundamental floating-point formats supported by specific PTX instructions: bf16 (8-bit exponent, 7-bit mantissa), e4m3/e5m2 (8-bit FP formats), tf32 (reduced-precision 32-bit for matrix ops), e2m1 (4-bit), e2m3/e3m2 (6-bit), ue8m0, and ue4m3. Details packing requirements and register declaration types for each format.
