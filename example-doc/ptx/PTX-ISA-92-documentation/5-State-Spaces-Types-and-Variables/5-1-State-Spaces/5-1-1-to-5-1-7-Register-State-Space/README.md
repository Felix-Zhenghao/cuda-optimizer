# Register State Space (5.1.1 to 5.1.7)

Merged from: 5-1-1-Register-State-Space to 5-1-7-Shared-State-Space

Covers PTX state spaces: registers (.reg) for fast per-thread storage, special registers (.sreg) for platform-specific values, banked constant space (deprecated), global (.global) for cross-thread communication, local (.local) for per-thread private memory, and shared (.shared) for CTA/cluster-accessible memory with broadcast optimizations.
