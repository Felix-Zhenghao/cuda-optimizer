# Kernel Function Parameters (5.1.6.1 to 5.1.6.3)

Merged from: 5-1-6-1-Kernel-Function-Parameters to 5-1-6-3-Kernel-Parameter-Attribute-ptr

Describes kernel function parameters declared in .param state space, which are addressable, read-only, and shared across all CTAs. Covers the .ptr attribute for indicating pointer parameters, specifying target state space and alignment. Includes syntax and examples for ld.param access patterns.
