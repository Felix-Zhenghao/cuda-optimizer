# 5.5.4.1. Im2col Mode Bounding Box

Defines bounding box semantics in im2col mode using DHW space with Lower-Corner/Upper-Corner coordinates, Pixels-per-Column, and Channels-per-Pixel parameters. Explains how tensor coordinates specify starting offsets in N/C dimensions and convolution filter base in DHW dimensions, with im2col offsets adjusting the access location.
