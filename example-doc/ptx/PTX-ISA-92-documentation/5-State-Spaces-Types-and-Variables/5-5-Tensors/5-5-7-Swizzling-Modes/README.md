# 5.5.7. Swizzling Modes

Documents shared memory swizzling modes for optimized access patterns: no swizzle, 32-byte, 64-byte, 96-byte, and 128-byte modes. The 128-byte mode supports sub-modes (16B/32B/64B atomicity, plus 32B with 8B flip). Includes swizzle pattern tables, alignment requirements, base offset formulas, and detailed figures for each mode.
