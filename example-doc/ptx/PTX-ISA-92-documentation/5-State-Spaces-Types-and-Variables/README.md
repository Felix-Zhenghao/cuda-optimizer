# 5. State Spaces, Types, and Variables

- **5-1-State-Spaces** -- Memory state spaces: register, special register, constant, global, local, shared, and parameter.
- **5-2-Types** -- Fundamental types, alternate FP formats (bf16, e4m3, tf32, etc.), fixed-point, and packed data types.
- **5-3-Texture-Sampler-and-Surface-Types** -- Opaque types for texture/sampler/surface with properties and OpenCL channel enums.
- **5-4-Variables** -- Variable declarations, vectors, arrays, initializers, alignment, and attributes (.managed/.unified).
- **5-5-Tensors** -- Tensor access modes (tiled, im2col), interleave layouts, swizzling modes, and tensor maps.
