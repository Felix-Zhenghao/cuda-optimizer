# Variable Declarations (5.4.1 to 5.4.3)

Merged from: 5-4-1-Variable-Declarations to 5-4-3-Array-Declarations

Covers PTX variable declaration syntax: state space, type, name, optional array size, and initializer. Explains vector types (.v2, .v4) with 128-bit max length and alignment rules. Describes array declarations with C-like dimensional syntax, including implicit first-dimension sizing from initializers.
