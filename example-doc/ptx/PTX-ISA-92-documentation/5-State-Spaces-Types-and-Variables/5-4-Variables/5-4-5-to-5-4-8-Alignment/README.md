# Alignment and Variable Attributes (5.4.5 to 5.4.8)

Merged from: 5-4-5-Alignment to 5-4-8-Variable-and-Function-Attribute-Directive-attribute

Covers .align directive for byte alignment (power-of-two, applies to array start address), parameterized variable names (%r<100> syntax for bulk register declaration), and .attribute directive for special properties like .managed (UVM) and .unified (same address on host/device, requires sm_90+).
