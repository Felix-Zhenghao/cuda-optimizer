# 2.2. Thread Hierarchy

- **2-2-1-Cooperative-Thread-Arrays** -- Defines CTAs, thread identifiers, synchronization barriers, and SIMT warp execution.
- **2-2-2-Cluster-of-Cooperative-Thread-Arrays** -- Clusters of CTAs that synchronize and share memory, available on sm_90+.
- **2-2-3-Grid-of-Clusters** -- Grids batch clusters for large kernel launches with grid-level identifiers and dependencies.
