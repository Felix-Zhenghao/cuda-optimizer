# 2. Programming Model

- **2-1-A-Highly-Multithreaded-Coprocessor** -- GPU as a massively parallel coprocessor executing kernel functions compiled to PTX.
- **2-2-Thread-Hierarchy** -- Thread organization: CTAs, clusters of CTAs, and grids of clusters.
- **2-3-Memory-Hierarchy** -- Memory state spaces: local, shared, global, constant, texture, and surface memory.
