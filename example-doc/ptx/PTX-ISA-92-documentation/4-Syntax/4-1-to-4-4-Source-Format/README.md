# 4.1-4.4: Source Format, Comments, and Identifiers

Covers PTX source module basics: ASCII text format, whitespace handling, C preprocessor support, comment syntax (C/C++ style), case sensitivity, and identifier naming rules. Includes a table of predefined identifiers such as special registers (`%tid`, `%ctaid`, `%clock`, etc.) and the `WARP_SZ` constant.
