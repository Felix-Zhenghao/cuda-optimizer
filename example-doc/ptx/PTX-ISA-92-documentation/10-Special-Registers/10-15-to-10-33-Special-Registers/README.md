# 10.15-10.33: Special Registers (Cluster, Lane Masks, Timers, Counters, Memory)

Covers cluster CTA count and rank registers (%cluster_nctaid, %cluster_ctarank, %cluster_nctarank), lane mask registers (%lanemask_eq/le/lt/ge/gt), clock and timer registers (%clock, %clock64, %globaltimer), performance monitor counters (%pm0-%pm7, %pm0_64-%pm7_64), driver environment registers (%envreg), shared memory size registers, and the %current_graph_exec register.
