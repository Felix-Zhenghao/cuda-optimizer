# 10.1-10.14: Special Registers (Thread, CTA, Grid, Cluster)

Documents PTX special registers for thread identification (%tid, %ntid), lane and warp IDs (%laneid, %warpid, %nwarpid), CTA and grid identifiers (%ctaid, %nctaid, %smid, %nsmid, %gridid), and cluster-related registers (%is_explicit_cluster, %clusterid, %nclusterid, %cluster_ctaid). Each register includes syntax, description, ISA version history, and target architecture requirements.
