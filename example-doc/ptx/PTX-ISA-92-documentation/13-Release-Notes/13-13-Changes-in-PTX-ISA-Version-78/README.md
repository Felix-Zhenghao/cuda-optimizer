# 13.13: Changes in PTX ISA Version 7.8

Major release adding sm_89 and sm_90 targets with cluster support. Introduces .cluster scope, cluster-level shared memory visibility, barrier.cluster, mapa, and getctarank instructions. Adds new floating-point formats (.e4m3, .e5m2), griddepcontrol, movmatrix, stmatrix, and cluster dimension directives.
