# 13.7-13.12: Changes in PTX ISA Versions 8.0-8.5

Covers PTX ISA versions 8.0 through 8.5. Version 8.0 adds sm_90a, wgmma, bulk async copy, and setmaxnreg. Version 8.1 adds st.async, red.async, multimem instructions. Version 8.2 extends wgmma with sparsity. Version 8.3 adds .b128 type and tensormap support. Version 8.4 extends FP8 for mma. Version 8.5 adds mma.sp::ordered_metadata.
