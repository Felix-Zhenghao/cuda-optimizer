# 13.1-13.3: Changes in PTX ISA Versions 9.0-9.2

Covers PTX ISA versions 9.0 through 9.2. Version 9.0 adds sm_88 and sm_110 targets, .blocksareclusters directive, .abi_preserve directives, enable_smem_spilling and frequency pragmas. Version 9.1 adds .volatile local loads/stores and new conversion types. Version 9.2 adds .u8x4/.s8x4 support and new instruction extensions.
