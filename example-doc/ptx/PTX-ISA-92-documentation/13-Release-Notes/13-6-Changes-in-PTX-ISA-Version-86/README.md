# 13.6: Changes in PTX ISA Version 8.6

Major release adding sm_100 and sm_101 targets. Introduces tcgen05 instruction family for tensor core operations, clusterlaunchcontrol instruction, st.bulk instruction, and mixed-precision floating-point arithmetic. Extends fence, ldmatrix, stmatrix, cp.async.bulk.tensor, and multimem instructions. Adds redux.sync with .f32 support.
