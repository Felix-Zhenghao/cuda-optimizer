# 13.4: Changes in PTX ISA Version 8.8

Introduces sm_103, sm_121 targets and family-specific "f" suffix architectures (sm_100f, sm_101f, sm_103f, sm_120f, sm_121f). Extends min/max to three inputs, tcgen05.mma with new scale qualifiers, 256b load/store operations, and tcgen05.ld.red instruction. Includes comprehensive family-specific feature promotion table.
