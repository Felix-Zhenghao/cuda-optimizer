# 13.39: Changes in PTX ISA Version 2.0

Documents the major PTX ISA 2.0 release for sm_20 targets. Adds IEEE 754 floating-point compliance, fma.f32, subnormal number support, and new rounding modifiers. Introduces ldu, clz, bfind, brev, bfe, bfi, popc, vote.ballot, membar.sys, generic addressing, cache operations, SIMD video instructions, and the .section debugging directive.
