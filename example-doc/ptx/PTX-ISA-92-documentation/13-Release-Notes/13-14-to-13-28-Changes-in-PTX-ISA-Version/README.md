# 13.14-13.28: Changes in PTX ISA Versions 5.0-7.7

Covers versions 5.0 through 7.7. Key additions include sm_60-sm_87 targets, memory consistency model (6.0), wmma/mma matrix instructions (6.0+), bf16/tf32 formats (7.0), async copy and mbarrier (7.0), cache eviction policies (7.4), fence.proxy (7.5), stack manipulation (7.3), activemask (6.2), nanosleep (6.3), and dp4a/dp2a (5.0).
