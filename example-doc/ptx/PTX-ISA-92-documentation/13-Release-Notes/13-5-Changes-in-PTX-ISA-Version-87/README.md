# 13.5: Changes in PTX ISA Version 8.7

Introduces sm_120 target architecture and sm_120a for architecture-specific features. Extends tcgen05.mma with mxf4nvf4 and scale_vec::4X. Adds FP8 accumulator support for mma, .rs rounding mode for cvt, and extends st.async/red.async with .mmio, .release, .global qualifiers. Updates gather4/scatter4 coordinate semantics.
