# 13.29-13.38: Changes in PTX ISA Versions 2.1-4.3

Covers versions 2.1 through 4.3. Key additions include indirect call support and .callprototype (2.1), .address_size directive (2.3), sm_30 and SIMD video instructions (3.0), CUDA Dynamic Parallelism and sm_35 (3.1), .f16 support and sm_53 (4.2), lop3 instruction (4.3), and 64-bit performance counters (4.0).
