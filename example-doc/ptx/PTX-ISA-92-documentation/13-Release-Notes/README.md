# 13. Release Notes

- **13-1-to-13-3-Changes-in-PTX-ISA-Version-9** -- PTX ISA 9.0-9.2: sm_88, sm_110 targets, new pragmas, .abi_preserve directives.
- **13-4-Changes-in-PTX-ISA-Version-88** -- PTX ISA 8.8: sm_103/sm_121, family-specific "f" targets, tcgen05 extensions.
- **13-5-Changes-in-PTX-ISA-Version-87** -- PTX ISA 8.7: sm_120 target, FP8 extensions, st.async enhancements.
- **13-6-Changes-in-PTX-ISA-Version-86** -- PTX ISA 8.6: sm_100/sm_101, tcgen05 instructions, mixed-precision arithmetic.
- **13-7-to-13-12-Changes-in-PTX-ISA-Version-8** -- PTX ISA 8.0-8.5: sm_90a, wgmma, async operations, tensormap.
- **13-13-Changes-in-PTX-ISA-Version-78** -- PTX ISA 7.8: sm_89/sm_90, cluster support, new FP formats.
- **13-14-to-13-28-Changes-in-PTX-ISA-Version** -- PTX ISA 5.0-7.7: memory model, matrix instructions, bf16/tf32.
- **13-29-to-13-38-Changes-in-PTX-ISA-Version** -- PTX ISA 2.1-4.3: indirect calls, SIMD, Dynamic Parallelism.
- **13-39-Changes-in-PTX-ISA-Version-20** -- PTX ISA 2.0: IEEE 754 compliance, generic addressing, many new instructions.
